# Gloire Projet - Excel VBA

Projets d'automatisation sous Excel VBA : traitement documentaire, OCR et controles fournisseurs.

## Projets

| Projet | Objectif | Presentation |
| --- | --- | --- |
| GLOIRE V2 | Lecture OCR, identification, renommage et classement des factures fournisseurs | [Decouvrir](presentations/GLOIRE_V2.md) |
| Remplissage Cegide OCR | Extraction des operations HT/debours d'une facture et preparation des lignes dans Excel | [Decouvrir et installer](presentations/REMPLISSAGE_CEGIDE_OCR.md) |
| FOURNISSEUR V1 | Controle des informations fournisseurs | [Decouvrir](presentations/FOURNISSEUR_V1.md) |
| NOUVEAU SIREN V1 | Recherche d'une continuite juridique apres cessation | [Decouvrir](presentations/NOUVEAU_SIREN_V1.md) |

Les sources se trouvent dans `src/`. Les projets OCR ont des finalites differentes : **GLOIRE V2 classe les documents ; Remplissage Cegide OCR prepare leurs operations dans Excel.**

Les factures reelles, classeurs metier, donnees clients et sorties OCR ne sont pas fournis. Toujours travailler sur une copie du classeur et verifier les resultats avant tout import comptable.
